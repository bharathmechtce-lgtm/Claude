# Data Exchange

Drop zone for feeding data into the project **without touching the main structure**.

- **`inbox/`** - Drop any files here (chat exports, product lists, customer lists)
- **`processed/`** - Files moved here after being consumed

Prefix with client name for clarity: `TJUK_new_products.xlsx`, `ACS_customer_update.csv`

This folder is gitignored (except READMEs and .gitkeep files).
